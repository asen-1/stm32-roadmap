# STM32 嵌入式学习路线（F103C8T6）

个人学习记录：从「点灯」到「ADC 采样」，每一步都**关掉教程自己重建**。

- 硬件：STM32F103C8T6（小蓝板，Cortex-M3 / 72MHz / 64KB Flash / 20KB RAM）
- 工具链：STM32CubeMX + Keil MDK5 + ST-Link
- 学习目标：**电源硬件方向**（数字电源 = ADC 采样 + PWM 输出 + 环路控制，STM32 是地基）

---

## 目录结构

| 目录 | 阶段 | 内容 | 关键点 |
|---|---|---|---|
| `template-72m-uart-led` | 0 | 干净工程模板 | 72MHz + 串口 printf + LED |
| `stage1a-exti-key` | 1 | 外部中断（EXTI） | 按键下降沿 + NVIC + 回调 |
| `stage1b-tim2-debounce` | 1 | 定时器中断 + 采样消抖 | 每 10ms 采样，连续 2 次一致才认 |
| `stage2-uart-cmd` | 2 | 串口中断接收 + 命令解析 | 行缓冲 + `\r\n` 结束符 + `strcmp` |
| `stage3-adc` | 3 | ADC 单次采样 + 电压换算 | PA1 / 12MHz / 全整数换算 |

## ⚠️ 关于 `Drivers/` 目录

仓库里**没有提交** `Drivers/`（CMSIS + HAL 源码，单个工程约 65MB），因为：

1. 它完全可以由 `.ioc` 重新生成
2. 体积太大，不值得进版本库

**恢复方法（二选一）**：

**方法 A：用 CubeMX 重新生成**
1. 用 STM32CubeMX 打开对应目录下的 `*.ioc`
2. 点 `GENERATE CODE`
3. `Drivers/` 和 Keil 工程文件会重新生成

**方法 B：从已有工程复制**
把任意一个完整工程的 `Drivers/` 文件夹复制到本工程根目录下即可。

> 你自己的 `USER CODE` 全部在 `Core/Src/*.c` 里，不会被覆盖。

## 几条代码纪律

1. **每学一个外设，关掉教程自己重建一次**（所以每个阶段都有原版和 `remake` 版）
2. **中断里只做「不做就会丢」的事**，其余交给主循环
3. **事件用完必须清零，状态只在变化时动作**
4. **编译通过 ≠ 逻辑正确**——先问一句「这段代码会在什么时机执行」

## 踩坑记录（博客同款）

| 坑 | 根因 |
|---|---|
| 按键按一下翻两次 | 松手回弹被当成了一次新的「按下」→ 改用采样消抖 |
| 串口发命令没反应 | ① 工具没发换行 ② 代码只认 `\n` 不认 `\r` |
| `[RX]` 永远不打印 | 花括号错位，`if(line_ready)` 跑到了 `while(1)` 外面 |
| ADC 读数 4038 而非 4095 | 实际 VDDA 是 3.253V，不是标称 3.3V |
| 接上分压就断电 | 3.3V 和 GND 被直连，不是电阻的问题 |
