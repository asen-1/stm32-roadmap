## 一、先记什么（数据结构设计）

```
记忆区：
    ---- 按键相关 ----
    key_state   : 按键当前的稳定状态        （1=松开，0=按下）
    low_cnt     : 连续读到「低」的次数
    high_cnt    : 连续读到「高」的次数
    key_event   : 「刚才按了一下」的标记      （一次性，用完清）
    tick_cnt    : 心跳计数（数到 50 就是 500ms）
    tick_500    : 「该打印心跳了」的标记      （一次性，用完清）

    ---- 串口相关 ----
    rx_byte     : 刚收到的那一个字节
    line_buf[]  : 正在拼的这一行
    line_len    : 已经拼到第几个字符了        （游标）
    line_ready  : 「一整行拼完了」的标记      （一次性，用完清）
    rx_count    : 一共收了多少字节            （调试用）
```

**设计口诀：**
- **状态**（state）回答「现在是什么样」，是持续的
- **标记/事件**（flag）回答「刚才发生了一次」，是一次性的
- 中断里**只置标记**，主循环**只清标记**

## 二、初始化（只做一次）

```
初始化外设（CubeMX 生成的）

启动定时器 2 的中断（每 10ms 来一次）

启动串口接收：等 1 个字节
```

---

## 三、每 10 毫秒执行一次（定时器中断回调）

```
读一次 PA0 的电平 → 存进 raw

如果 raw 是「低」：
    高计数清零
    低计数 = 低计数 + 1

    如果 低计数 >= 2（连续 20ms 都是低）：
        低计数清零
        如果 当前状态还是「松开」：
            状态改成「按下」
            置「按了一下」的标记

否则（raw 是「高」）：
    低计数清零
    高计数 = 高计数 + 1

    如果 高计数 >= 2（连续 20ms 都是高）：
        高计数清零
        状态改成「松开」          ← 只是恢复状态，**不产生标记**

心跳计数 = 心跳计数 + 1
如果 心跳计数 >= 50（50 × 10ms = 500ms）：
    心跳计数清零
    置「该打印心跳」的标记
```

---

## 四、每收到 1 个字节执行一次（串口中断回调）

```
收到总数 = 收到总数 + 1

如果 这个字节是「回车」或「换行」：
    如果 这一行不是空的：
        缓冲区末尾补上结束符 '\0'
        置「一行收完了」的标记
        游标归零
    （这一行是空的 → 什么都不做，比如 \r\n 里的那个 \n）

否则：
    如果 缓冲区还有空位：
        把这个字节放进缓冲区
        游标 = 游标 + 1

重新启动串口接收：再等 1 个字节        ← 忘了这句，只收得到一个字节
```

---

## 五、主循环（一直重复）

```
重复执行：

    如果 有「按了一下」的标记：
        清掉标记
        翻转 LED
        打印按下时间

    如果 有「该打印心跳」的标记：
        清掉标记
        打印 tick 和时间

    如果 有「一行收完了」的标记：
        清掉标记
        如果 这一行是 "led on"   → 灯亮，打印 LED ON
        否则如果 是 "led off"    → 灯灭，打印 LED OFF
        否则                     → 打印 unknown
```

## 六、伪代码 ↔ C 代码 对照表

| 伪代码 | C 代码 |
|---|---|
| 每 10ms 执行一次 | `void HAL_TIM_PeriodElapsedCallback(...)` |
| 读一次电平 | `uint8_t raw = HAL_GPIO_ReadPin(KEY_GPIO_Port, KEY_Pin);` |
| 连续 2 次低 | `if (++low_cnt >= 2)` |
| 状态从松开变按下 | `if (key_state != 0) { key_state = 0; key_event = 1; }` |
| 松开只恢复状态 | `key_state = 1;` |
| 置「按了一下」标记 | `key_event = 1;` |
| 每收到 1 个字节 | `void HAL_UART_RxCpltCallback(...)` |
| 是回车或换行 | `if (rx_byte == '\r' \|\| rx_byte == '\n')` |
| 这一行不是空的 | `if (line_len > 0)` |
| 补结束符 | `line_buf[line_len] = '\0';` |
| 置「一行收完了」标记 | `line_ready = 1;` |
| 放缓冲 + 防溢出 | `if (line_len < sizeof(line_buf)-1) line_buf[line_len++] = rx_byte;` |
| 重新等 1 个字节 | `HAL_UART_Receive_IT(&huart1, &rx_byte, 1);` |
| 有标记就处理并清掉 | `if (line_ready) { line_ready = 0; ... }` |
| 比较命令 | `if (strcmp(line_buf, "led on") == 0)` |

## 七、为什么这样分层（三条原则）

1. **节拍驱动的活放中断**：按键采样必须严格每 10ms 一次
2. **不等就丢的活放中断**：串口字节不马上搬走会被下一个覆盖
3. **其余全放主循环**：打印、比较、点灯 —— 它们会阻塞，进中断会丢数据
