## 三、坑二：呼吸灯变成了「锯齿」

**现象**：想写呼吸灯，结果看到的是「慢慢变亮 → 啪一下灭 → 又慢慢变亮」。

**我的代码**：

```c
if (pwm_dir > 0)
{
    if (pwm_ccr + 10 <= 1000)  pwm_ccr += 10;
    else                     { pwm_ccr = 0; pwm_dir = 1; }   // ← 错在这
}
```

**问题**：到顶之后应该「掉头往下」，我写成了「回到 0 重来」，所以变成锯齿而不是呼吸。

**正确写法**：

```c
else { pwm_ccr = 1000; pwm_dir = -1; }   // 到顶 → 反向
```

## 四、坑三：舵机嗡嗡响但完全不动

**现象**：串口正常打印 `servo -> 500 / 1500 / 2500 us`，舵机有嗡嗡声、有保持力矩，但一点不转。

**排查过程**（这一段是文章重点，写清每一步排除了什么）：

1. 怀疑 PWM 没输出 → 用万用表量 PA6 对 GND，**电压在变** → PWM 正常 ✅
2. 怀疑面包板短路 → 检查接线 → 正常 ✅
3. 怀疑舵机坏了 → （你补充：怎么排除的）
4. **发现信号线插到了 5V 引脚** → 恒高电平 = 舵机认为「脉宽超限」→ 拼命转但转不动

**正确的舵机接线**：

| 舵机线 | 接到 |
|---|---|
| 棕/黑 | GND |
| 红 | 5V |
| 橙/黄 | PA6（PWM 信号） |

## 五、坑四（核心）：标着「5V」的引脚，实测只有 3.3V

这是最有价值的一条。

**背景**：小蓝板的 `5V` 引脚是从 USB 的 5V 经一个二极管过来的：

```
USB 5V ──[二极管]── 5V 引脚 ──[LDO]── 3.3V 轨
```

**我犯的错**：板子是靠 **ST-Link 的 3.3V** 供电的，**没有插 USB**。

**结果**：
- 3.3V 轨有电 ✅
- 但 **5V 节点根本没有 5V 源**，量出来只有 3.3V 左右（从 3.3V 轨反串过来）
- SG90 额定 4.8–6V，吃 3.3V 时**力矩小到推不动自己** → 嗡嗡响、不转

**解决办法**：

1. 插上 USB 数据线给板子供电（5V 引脚就有真 5V 了）
2. **同时把 ST-Link 的 3.3V 线拔掉**——否则两个 3.3V 电源并联，轻则发热，重则烧 ST-Link
3. ST-Link 只保留 SWDIO / SWCLK / GND 三根线，下载调试照常可用

**实测数据**（贴你自己的数字）：

| 状态 | 5V 引脚电压 | 舵机表现 |
|---|---|---|
| 只靠 ST-Link 3.3V 供电 | 3.3 V | 嗡嗡响，不转 |
| 插上 USB 后 | ____ V | 正常转动 |

## 六、可复用的三条硬件通则

1. **引脚丝印 ≠ 实际电压**，关键引脚先用万用表量一遍
2. **电机类负载优先独立供电**，控制信号和电源分开；如果共用电源，注意不要两个电源并联
3. **调硬件先排除硬件**：量电压 → 测通断 → 再看代码
